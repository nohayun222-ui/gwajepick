# 과제픽 (GwajePick) — 실행 가능한 프런트엔드 MVP

## 현재 작동하는 기능
- Wikimedia Commons 실시간 검색 API 연결 (한국어 검색어 입력 가능)
- 카테고리별 검색, 라이선스/확인상태/이용조건 필터
- Commons 이미지 미리보기, 상세정보, 원본 페이지 및 라이선스 링크
- MY PICK 저장/취소 (현재 브라우저의 localStorage)
- 기본형·APA·MLA 출처 텍스트 복사
- 사용자 자료 등록 및 오류 신고의 로컬 임시 저장
- 반응형 PC/모바일 레이아웃, 검색 재시도, 이미지 로딩 실패 안내

## 실행
1. `index.html`을 Chrome, Edge 등 최신 브라우저에서 엽니다.
2. 인터넷 연결이 필요합니다. Wikimedia Commons API에서 검색합니다.
3. 클립보드 복사는 HTTPS 또는 localhost 환경에서 가장 안정적으로 작동합니다.

## 반드시 알아둘 제한
이 패키지는 서버 없이 실행되는 프런트엔드 MVP입니다.
- MY PICK, 자료 등록 초안, 신고 초안은 해당 브라우저에만 저장됩니다.
- 학생 등록 자료가 공개 자료실에 게시되지 않습니다.
- 신고가 운영자에게 전송되지 않습니다.
- 운영자 로그인/권한 관리/검토 기능은 아직 연결되지 않았습니다.
- 운영자 확인 배지는 실제 확인이 수행되지 않았으므로 모든 Commons 결과에 '운영자 확인 전'을 표시합니다.
- Commons의 메타데이터는 원본 제공자가 입력한 정보입니다. 라이선스 표기만으로 법률적 이용 가능성을 보증하지 않습니다. 원본 파일 페이지와 라이선스 전문을 확인하세요.
- Commons 검색은 영어 키워드가 더 많은 결과를 찾는 경우가 있습니다. 한국어 검색어가 충분한 결과를 반환하지 않으면 비슷한 영어 검색어도 시도해 보세요.

## 여러 사용자 공유 및 운영자 기능을 완성하려면
`supabase_schema.sql`은 데이터베이스 구조와 권한 정책의 시작 템플릿입니다. Supabase 프로젝트를 만들고 SQL을 적용한 뒤, 프런트엔드에 Supabase Auth/DB 연결 코드를 추가해야 공유 등록, 신고 전달, 운영자 검토가 실제로 활성화됩니다. 현재 앱은 그 기능이 연결된 것처럼 가장하지 않습니다.

## 저작권 관련
CC BY, CC BY-SA, CC BY-NC, CC BY-ND, CC0, Public Domain은 서로 다른 조건입니다. 특히 NC는 상업적 이용 제한, ND는 변경·편집 제한, SA는 동일조건 공유 의무가 핵심입니다. CC0와 퍼블릭 도메인도 국가별 저작권·초상권·상표권 등 다른 권리가 남을 수 있습니다.


## 연결 오류 점검
검색 실패 화면에 표시되는 오류 메시지를 확인하세요. `Failed to fetch`/접속 실패는 대체로 네트워크, 학교·기관 방화벽, 브라우저 확장 프로그램 또는 미리보기 환경의 외부 API 차단 문제입니다. `HTTP 4xx/5xx` 또는 API 오류 코드는 서버가 반환한 구체적인 오류입니다. 앱에는 Wikimedia의 직접 검색 페이지로 이동하는 대체 링크와 재시도 기능이 포함되어 있습니다.
